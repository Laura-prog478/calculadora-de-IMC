Isto é uma aplicação web simples e funcional para calcular o Índice de Massa Corporal (IMC). Este projeto foi desenvolvido para praticar a manipulação do DOM (Document Object Model) e a lógica de programação com JavaScript . - Funcionalidades |Cálculo Preciso: Calcula o IMC com base no peso e altura informados. |Classificação em Tempo Real: Informa se o usuário está abaixo do peso, no peso ideal, com pré-obesidade ou em níveis de obesidade (grau 1, 2 ou mórbida). |Validação de Campos: Exibe um alerta caso o usuário tente calcular sem preencher todos os dados. |Interface Amigável: Retorna uma mensagem personalizada com o nome do usuário e seu status de saúde. -Tecnologias UtilizadasHTML5: Estrutura da página e campos de entrada.CSS3: Estilização e lo ayout.JavaScript (ES6): Lógica de cálculo, condicionais e manipulação de eventos.
